Mở bằng file:// thì YouTube chặn phát (lỗi 153). Hãy đưa file này lên https (GitHub Pages, Netlify…) rồi mở bằng link đó.

Nạp phụ đề cho video đang phát

Tải file .srt/.vtt hoặc dán nội dung. Với video YouTube: mở trên youtube.com → “Hiện bản chép lời” → chọn hết → sao chép → dán vào ô dưới.
